# EDA_Task6
Healthcare Data Exploratory Data Analysis (EDA)
📌 Project Overview
This project performs Exploratory Data Analysis (EDA) on a healthcare dataset using Python. It explores patient information, medical conditions, hospital admissions, billing amounts, and relationships between numerical variables.

🎯 Objectives
Understand the structure of the healthcare dataset.
Identify and handle missing values.
Clean and prepare data for analysis.
Analyze patient admissions and billing amounts.
Visualize trends and correlations in healthcare data.
🛠️ Technologies Used
Python
Pandas
NumPy
Matplotlib
Seaborn
Google Colab / Jupyter Notebook
📂 Project Contents
EDA_TASK5.ipynb – Notebook containing data cleaning, analysis, and visualizations.
healthcare_data_for_task.csv – Healthcare dataset used for analysis.
🔍 Analysis Performed
Loaded and explored the healthcare dataset.
Checked dataset shape, columns, data types, and summary statistics.
Identified and handled missing values.
Cleaned admission type values.
Converted admission and discharge dates into datetime format.
Calculated hospital stay duration.
Analyzed billing amounts by medical condition.
Compared admissions across medical conditions and gender.
Visualized admission types and billing distributions.
Analyzed monthly patient admissions.
Created a correlation matrix and heatmap for numerical variables.
